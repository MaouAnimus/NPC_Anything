# Propuestas y Parches (Isolation Sandbox)

Este directorio es el único espacio donde el agente de ingeniería tiene autorización para escribir parches sugeridos (`*.patch`, `*.diff`, o propuestas de arquitectura).

**Regla de seguridad (Nivel N2 / AGENTS.md):**
- Ningún parche generado por agentes o herramientas automáticas debe aplicarse directamente al código fuente (`src/` o `demo/`) sin la previa revisión y aprobación explícita humana.
